# Private on purpose

Nothing here is committed. What is here on the author's machine is the pre-protocol community
batch (protocol, amendment of 2026-10-04), the working file built from it, and, in `private/ingest/`,
the batch read from the author's own Messages database (same amendments; participant `AUTHOR`, not
yet appended); `private/provenance.csv` says where each submission came from. No message may be collected *under the protocol* until it is
approved and the consent form is filled.
`scripts/sms_collect.py --check` says what is still missing. The community batch was gathered while that
command reported `ready_to_collect: false`; its provenance is recorded, its consent is not, and that
cannot be fixed afterwards — consent is not obtainable retroactively. The ethics application asks
whether it may be used anyway. Nothing further is collected until the command says yes.
